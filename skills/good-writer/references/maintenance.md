# 迭代与公开同步

- 按用户明确反馈做最小改进，区分本次约束与跨任务偏好，记录可复现的缺陷和匿名化规则，不记录聊天原文、身份、报告正文、截图、账号、配置或机密材料。
- 修改前读取最新 skill，保留 goodWriter 的真实材料、事实边界、总结与摘要区别、局部修改和视觉核验原则。更新相关评测，用虚构材料复验；不为了有更新而改动。
- 自动调用依赖技能安装与当前产品支持，不能宣称所有普通 GPT 聊天都可强制加载本技能。
- 定期同步由已配置的计划任务执行，技能本身不创建定时器。沿用用户指定的 GitHub 仓库，仅公开通用规则、工具说明与虚构测试，不上传私有原始资料。
- 同步前审查差异与来源许可，保留来源说明。没有实质改动时不提交；遇到权限或许可不明则保留本地变更并报告，不强制覆盖远端。

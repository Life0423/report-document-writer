# 交付前检查

## 内容
- 回答了用途和读者核心问题；满足本次必填项、长度和格式。
- 重要事实有来源；引用确实支持句子，链接/书目信息可定位。
- 数字、单位、日期、人名、项目名、合计及图表一致。
- 事实、推断、计划和未知明确区分；没有虚构结果或补出私人经历。
- 结论不超出证据；反例、限制和未决项没有被润色删除。
- 图片中的数量、标签及文字已实际检查。

## 表达
- 结构顺序符合文种；标题准确概括内容。
- 段落有信息密度，无反复改写同一结论来凑字数。
- 使用真实样本支持的风格，不把助手惯用句误当用户口吻。
- 保留原有立场，未增加未经确认的责任、保证或敏感披露。

## 文件与版式
- 按目标工具实际渲染/打开；抽查不足以声称每页通过。
- 检查所有页面的裁切、溢出、孤立标题、乱码/缺字、表格分页、页码和图片清晰度。
- 目录、章节、图表编号、交叉引用与附件一致。
- 清除模板占位、批注、修订痕迹中的意外信息；用户要求保留的修订则保留。
- 未确认内容明确标记；源文件可编辑，附件可以正常打开。

## 最终说明
简短给出：成稿/附件、必要的待确认项、确实未验证的限制。不要用“完美”“全部正确”掩盖未完成检查。未经授权不发送到第三方、不发布、不签署。
